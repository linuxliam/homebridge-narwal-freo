Security system

When a robot starts cleaning and the security system is armed Away, it's switched to Stay, so the motion sensors don't see the robot; when the job ends (and every other robot is done too) it goes back to Away. If the security system can't be reached, the clean is refused rather than risking a false alarm.

Leave empty for homebridge-ecobee-security 0.2.0 or newer. Other security plugins or services can offer the same hold API (see "Security hold API" in the plugin's README): enter a Unix socket path or an http(s) URL.
